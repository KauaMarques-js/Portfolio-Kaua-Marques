# Captura da Flor Árabe

Adicione a captura real em `flor-arabe.webp`, preferencialmente em proporção 16:10. A página usa o nome do projeto enquanto o arquivo não existe, sem gerar requisições de imagem quebrada.

Depois de adicionar a imagem, ajuste `imageAlt` em `src/data/portfolio.ts` para descrever a tela e execute novamente o build. A captura deve omitir dados pessoais e informações sensíveis.
